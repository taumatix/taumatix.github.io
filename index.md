Small, well-tested libraries for Go and Swift. Each says which upstream version it was built
against, and a scheduled check tells us when that drifts.

## Libraries

- **[claude-agent-sdk-go](https://github.com/taumatix/claude-agent-sdk-go)**: unofficial Go SDK for the Claude Agent API, ported from the official Python SDK. [Docs](https://pkg.go.dev/github.com/taumatix/claude-agent-sdk-go).
- **[natsmqtt5](https://github.com/taumatix/natsmqtt5)**: an MQTT v5 broker that uses the NATS server you already run as its messaging core. [Docs](https://pkg.go.dev/github.com/taumatix/natsmqtt5).
- **[claude-mods-go](https://github.com/taumatix/claude-mods-go)**: write Claude Code mods in Go. [Docs](https://pkg.go.dev/github.com/taumatix/claude-mods-go).
- **[anthropic-swift](https://github.com/taumatix/anthropic-swift)**: Swift client for the Anthropic Claude API.
- **[iterm2-go](https://github.com/taumatix/iterm2-go)**: Go client for the iTerm2 API. [Docs](https://pkg.go.dev/github.com/taumatix/iterm2-go).
- **[iterm2-claude-bridge](https://github.com/taumatix/iterm2-claude-bridge)**: show Claude Code sessions on remote hosts in iTerm2.

## About

Most of the day-to-day work on these libraries is done by an AI agent; a human owns the
repositories and sets the direction. Everything is Apache-2.0 apart from the two iTerm2 libraries,
which are GPL-2.0-or-later because they include iTerm2's own protocol definition.
