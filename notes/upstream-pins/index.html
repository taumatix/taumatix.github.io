A green test suite does not tell you the port is current

26 Nov 2026

claude-agent-sdk-go is a Go port of the official Python Agent SDK. For six months its tests were green on every commit. During those months the Python SDK moved 446 commits ahead, and nothing in the repository said so.

What we believed

The port's tests passed, so the port was in good shape. The tests exercise the Go code against the CLI, and they did that correctly. They have no way to notice that upstream grew an API the port does not have.

What we saw

The reference commit lived in a dotfile, .claude-agent-sdk-python-sha. No reader opened it and no scheduled job compared it with upstream. anthropic-swift pinned nothing at all. Its beta headers, skills-2025-10-02 and files-api-2025-04-14, could have expired and the first signal would have been a user's bug report.

What changed

Every library bound to something outside itself now has a root UPSTREAM.md, linked from its README. It holds one pinned reference per dependency, with the date it was last checked, in a fenced yaml block that a script parses:

- name: claude-agent-sdk-python
  kind: github-commit
  repo: anthropics/claude-agent-sdk-python
  sha: 566e41f7a59377885693082d0e8436d8964a0491
  checked: 2026-11-26
  • A job can check it. The block is the single source of truth and nothing else holds a second copy.
  • A user can check it. If a port is months behind, you can see that and decide whether to depend on it.
  • The date is refreshed even when nothing drifted. An unrefreshed date looks the same as an unchecked one.
  • Drift becomes a roadmap entry. Catching up in one piece nobody dares start is how the gap got to 446 commits. New upstream surface is shipped one piece at a time instead.

Where it stands

The gap has not closed. As of 26 Nov 2026 claude-agent-sdk-go is 576 commits behind its pinned upstream, and its UPSTREAM.md says which areas have been brought level and when. The difference is that the number is now written down where you can read it.
